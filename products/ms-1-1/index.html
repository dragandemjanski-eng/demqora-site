MS 1.1

Market Structure Multi-Timeframe Chart.

One chart. Multiple timeframes.

A controlled multi-timeframe structure workspace.

MS 1.1 combines the active chart timeframe with selected reference timeframes while keeping the display configurable from a dedicated control panel.

Reference TimeframesSelect reference timeframes and control their displayed structure.
Display PresetsUse predefined and custom display modes to manage visual density.
Trend & RangeKeep structural direction and range context visible in the chart workflow.
AlertsUse chart alerts for supported market-structure events.
Interface overview

Choose the display density that fits the workflow.

MS 1.1 includes five display presets, from a clean overview to a fully manual setup.

BasicEssential BOL lines and zones on the active timeframe, with a clear reference-timeframe view.
PerformanceA lighter display focused on the information needed for fast chart reading and smoother execution.
StandardA balanced view combining the main structural lines with useful context from selected reference timeframes.
FullThe richest predefined view, showing the broadest supported combination of structure, zones and context.
CustomManual control of BOL, POI and SM lines, zones and executed levels for each selected timeframe.
Structure framework

Core visual components

MS 1.1 organizes several market-structure components inside the same visual environment.

BOL

Break-of-level structure displayed through the chart system according to the selected timeframe and display mode.

POI

Point-of-interest structure visualized as part of the broader market-structure view.

SM

Smart-money structure integrated with the same timeframe and visual-control workflow.

Trend

Trend visualization provides directional context without requiring a separate chart workspace.

Range

Range visualization provides structural context for consolidation and range conditions.

Themes

Use supported chart themes to keep the interface readable across different viewing preferences.
