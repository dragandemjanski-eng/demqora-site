01 / Current release overview

MS 1.1 · Release 1

The first public release is focused on visualization, configurable market structure, notifications and manual decision support.

Scope documented

Initial product baseline

The features and operating principles documented for Release 1.

EA + Indicator
Market structure

Multi-timeframe BOL, POI and SM levels and zones, supported by Trend arrows and Range context on one MT5 chart.

Display controls

Basic, Performance, Standard, Full and Custom presets. Three optional reference-timeframe slots allow a selected amount of additional structure.

Pattern analysis

Candlestick-pattern identification and scoring are included as analytical assistance alongside structural chart information.

Alerts

Separate Pattern and Structure alert categories, controlled by MS 1.1 Inputs and the panel's Master ALERTS switch. Telegram notifications are optional.

Diagnostics

The Report Diagnostics workflow helps collect information when investigating a persistent or difficult-to-reproduce issue.

03 / Notifications

Alerts, with clear control.

Alerts are assistance, not a trade instruction. Pattern and Structure notifications can be enabled independently in MS 1.1 Inputs.

ControlPurpose
Pattern AlertsAllow or suppress supported candlestick-pattern notifications.
Structure AlertsAllow or suppress BOL, POI, SM and supported Range event notifications.
Panel ALERTSGlobal Master switch for alert delivery. It must be ON for enabled categories to notify.
Telegram AlertsOptional remote notification channel; requires separate configuration and an allowed WebRequest URL in MT5.
Important: Disabling Pattern or Structure alert delivery does not turn off the underlying chart analysis or market-structure visualization. See the relevant guides for event-specific conditions and setup.
